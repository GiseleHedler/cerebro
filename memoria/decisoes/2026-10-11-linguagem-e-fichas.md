# 11/10/2026 — Linguagem de função e fichas "versão para o agente"

- Gisele pediu um jeito de "dizer melhor" as coisas para avançar com o agente.
- Decisão: **trocar a doença pela função** (guia `marcas/natural-pure/atendimento/GUIA-DE-LINGUAGEM.md`). Quando o cliente cita doença, o agente acolhe, informa a composição, recomenda o profissional e passa para o time, sem dizer "não" e sem dizer "pode, sim".
- Cada ficha de produto ganhou uma seção **"Versão para o agente"**. O agente lê só essa seção; o texto do site fica abaixo como referência.
- Frases de benefício e alertas são **proposta**; os pontos menos firmes estão marcados "(RT confirmar)".
- Achados na revisão das páginas do site: a página do Amino Limonada Rosa traz colados os textos dos colágenos; os sabores dos colágenos estão trocados na lista de ingredientes; o Ultra C cita um ingrediente que não está na lista; e há a frase "Não sobrecarrega os rins: seguro para quem tem preocupações com a saúde renal". Tudo vai para o responsável técnico.
